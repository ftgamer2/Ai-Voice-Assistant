# AI Voice Assistant

**LYNX · FTGAMERV2**

A futuristic AI voice assistant with **Hinglish support**, real-time voice interactions, and cyberpunk UI. Features voice I/O, an animated avatar, conversation memory, file uploads, and offline capabilities.

## Live demo

[Experience the AI Assistant](https://ftgamer2.github.io/Ai-Voice-Assistant/)

## Features

- Voice input/output with Hinglish support
- Real-time animated avatar with mouth sync
- Conversation memory (last 10 messages)
- File upload support (images, PDF, text)
- Fully responsive, mobile-first design
- Quick command chips for common queries
- Usage statistics tracking
- Offline mode with cached responses

## Quick commands

- `/help` — Show all commands
- `/clear` — Clear chat history
- `/status` — Show system status
- `/stats` — View usage statistics
- `/time` — Get current time
- `/joke` — Hear a random joke
- `/voice on/off` — Toggle voice output

## Quick start

### GitHub Pages

1. Fork this repository.
2. Go to **Settings → Pages**.
3. Select the `main` branch as the source.
4. Your assistant will be available at: [ftgamer2.github.io/Ai-Voice-Assistant](https://ftgamer2.github.io/Ai-Voice-Assistant/)

### Local run

```bash
# Clone the repository
git clone https://github.com/ftgamer2/Ai-Voice-Assistant.git

# Open in a browser
open index.html

# Or use a local live server
npx live-server
```
